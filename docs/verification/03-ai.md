# 模块三验证结果（2026-10-17）

## 1. 环境

- 沙箱：Ubuntu 22.04、Temurin JDK 21.0.12、Maven 3.10.0。
- 沙箱无 Docker：Testcontainers 集成测试未运行。
- 沙箱无真实 API key：所有外部调用由 WireMock 模拟。
- 用户本机：IDEA + Docker + 真实 DeepSeek / DashScope key，负责运行与集成验证。

## 2. 编译与单测

命令：

```bash
mvn clean test -Dtest='!*IntegrationTest'
```

结果：

```text
total=54, failures=0, errors=0, skipped=0
```

覆盖：

- 非流式成功、401 / 400 / 429 / 500 映射、`Retry-After` 解析。
- SSE 正常结束、`: keep-alive` 忽略、`[DONE]`、断流、idle 超时、关闭幂等。
- 主备降级：主用重试、备用接管、非重试错误不降级、流式连接失败降级。
- Embedding：25 条输入分 3 批（10/10/5）、倒序 index 重排、维度不一致报错、429 重试。
- SSE 接口：`start / delta / done / error`、15s 心跳（测试用 50ms）、参数校验。
- `RecordAndGrowApplicationTests`：无 DB、无 key 时上下文可加载。

## 3. 打包与启动

```bash
mvn -DskipTests package
java -jar target/record-and-grow-0.0.1-SNAPSHOT.jar --server.port=18080
```
