# v0.1.0 最小端到端闭环

第一个能跑通的版本：一个问题进来，按时间范围检索个人记录，组装成带来源的上下文，交给模型流式回答。

## 能做什么

- `POST /api/chat` 同步回答，`POST /api/chat/stream` 流式输出
- 自然语言时间（上周三、最近半年、2026 年 3 月）解析成检索范围
- 回答中带 `[T1]..[Tn]`，与 `sources` 一一对应，每条来源可回查
- 未配置 key、数据库不可用直接返回 503，不建立 SSE

## 几个刻意的设计

- 检索全部发生在建立 SSE 之前，所以确定性失败保留 HTTP 语义，只有模型侧失败走 `event:error`
- Prompt 与 sources 由同一次组装产出，不做两套计算，引用不会漂
- 预算超出时先截单条，再丢整条，最后才动总预算 —— 牺牲信息完整度优先于牺牲条目数
- 上游中断时按 `partial` 标记，区分「已经答了一半」和「还没开始答」

## 验证

120 个非集成测试、15 个 Testcontainers 集成测试通过。本机实测五项：未配置 key、真实模型调用、无命中、停库、客户端取消，均符合预期。

## 还没有的

单轮无状态，不支持追问；只有一个知识源（时间线）；无前端；时间解析为规则实现，关键词只覆盖引号短语与 ASCII 词。
