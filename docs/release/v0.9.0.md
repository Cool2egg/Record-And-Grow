# v0.9.0 后端初步完成

第一个「前端以外全链路可演示」的版本：时间线、文档、图谱、记忆、Agent 编排、MCP、Skills 全部落地。

## 能做什么

- 时间线 CRUD + 自然语言时间窗检索
- 文档上传 / Tika 解析 / 分块 / pgvector / 关键词通道 / RRF + Rerank
- 知识图谱：Postgres 默认，Neo4j / LightRAG 可选，外部存储失败自动回落
- 记忆：会话历史 + 滚动摘要 + PENDING / FACT / INFERRED 三态 + 用户确认
- AgentScope 两段式编排：检索 Agent（ReAct + 工具）+ 回答 Agent（流式）
- SSE：`start → sources → delta… → done/error`，正文带 `[T]/[D]/[M]/[G]` 引用
- MCP Server：`/mcp` stateless，4 个只读工具
- Skills：`skills/*.md` 触发词匹配 + 热加载
- 无 key / 无 Neo4j / 无 LightRAG 均可启动；外部存储失败自动降级

## 关键设计

- 事实与推断分离：AI 只能写 PENDING，确认后才进 FACT / INFERRED
- 证据按来源配额（时间线 45% / 文档 35% / 记忆 10% / 图谱 10%），避免一路吃光预算
- 两段式而不是单 ReAct：保证 `sources` 先于第一个 `delta`，引用编号由 Java 侧分配
- 模型层 `thinking: disabled`，避免推理 token 挤占正文
- 图谱查询：Postgres/Neo4j 用实体词，LightRAG 直接传原问题（不把 2 字滑窗拼成 query）

## 验证

- `mvn test`：357 个测试，0 失败
- `mvn -Pintegration test`：391 个测试（357 单测 + 34 真库/集成），0 失败
- 真实 key 下验证：非流式对话、SSE、工具调用、文档引用、多轮、记忆确认、图谱 reindex
- 真实 LightRAG 1.5.7：写入（含 `file_source`）/ 异步处理 / `/query` / 应用 reindex + search
- 真实 Neo4j：HTTP 事务端点 + Basic Auth + Cypher 写入/查询冒烟
