## 2. 模块学习收获
-1 报错码设计：用http状态码作前缀，在其后面就可以用枚举具体到业务上的错误，具体要单独用到http状态码时候也可以拆出来用，有点巧妙

-2 异常处理器和advice：异常处理器类里写了很多异常处理方法，通过注解标注，对应各种抛出的异常。 在这个类上面加上@RestControllerAdvice注解后，
就可以让这个处理器作用在所有加了@（Rest）Controller注解的类上了这里的命名很贴切，很方便记忆相关功能用法。

-3 两层探活：其实就是既单独ping数据库看死活，也用健康检查类测试数据库实际功能能不能用，跑不动的时候方便看哪里出问题。
