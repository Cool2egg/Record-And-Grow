## 2. 模块学习收获
-1 文档原文不入库，Tika解析出的原始文本做统一清洗后叫（归一化原文normalized_text）入库。原文档存起来备用。

-2 切块策略：混合，先递归切块把句子分开，然后按句子贪心累加，再加一句超400token就切成chunk，重叠是按整句回退，要超60token为止
    （取主流15%chunk大小）。原子化时维护其heading，切块后heading会单独存在数据库，但算向量时会加在chunk前面一起算。
    数据库里会存charstart和charend字段，用来回看被检索chunk在实际normalized_text里的具体位置。用户问到也方便回答
